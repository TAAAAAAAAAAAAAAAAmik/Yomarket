# 07. Маркетинговые утверждения

**Этот документ обязателен к прочтению перед написанием любого текста о
продукте** — сайта, поста, рекламы, письма, описания в каталоге.

Три раздела:
* **SAFE** — можно писать публично как есть.
* **CONDITIONAL** — можно, но **только с оговоркой**, которая указана рядом.
  Оговорка не факультативна: без неё утверждение становится ложным.
* **UNSAFE** — нельзя ни в каком виде, включая «скоро» и «в разработке».

# CONDITIONAL CLAIMS

Формат: **утверждение** → *обязательная оговорка* → proof.

## «Мгновенная реакция на сообщение покупателя»
→ *Обязательная оговорка:* «горячие» чаты читаются **раз в 10 секунд**; если
маркетплейс попросит сбавить темп, интервал вырастет до двух минут, и бот
покажет это, а не скроет.
Proof: `bot/tasks/manager.py:539` (`_CHAT_FAST = 10.0`), `:540`
(`_CHAT_SLOW = 120.0`), `:541` (`_CHAT_BACKOFF`).
**Лучшая безопасная замена:** «ответ уходит за секунды, а не за часы».

## «Мгновенная выдача кода»
→ *Оговорка:* заказ замечается не позже чем через минуту, поставщик может
отдавать код до двух минут.
Proof: `_user_loop` спит 60 с; `_GIFT_POLL_CEILING = 120.0`.
**Замена:** «код уходит покупателю за пару минут, без вас».

## «Управление несколькими магазинами»
→ *Оговорка:* это **хранение и переключение**. Фоновая автоматика работает на
**активном** аккаунте, а не на всех сразу.
Proof: `bot/storage.py:463` (`get_token` — «Токен АКТИВНОГО аккаунта»);
все три цикла заводятся на него.
**Замена:** «все магазины в одном боте — переключайтесь, не подключая заново».

## «Автоматическое продвижение»
→ *Оговорка:* тратит **деньги продавца**; по умолчанию выключено; идёт через
панель продавца, а не через API.
Proof: `promo_position.auto_promote = False`; `bot/tasks/manager.py:4116`
(`_panel_bump`).

## «Создание товара из бота»
→ *Оговорка:* нужна подключённая **панель продавца**; это мастер из пяти
шагов, а не одно нажатие; ссылки в описании панель запрещает, кроме белого
списка.
Proof: `bot/handlers/create_ad.py`, `bot/automation/panel.py:3313`
(`PANEL_LINK_ALLOWED`).

## «Вывод средств из бота»
→ *Оговорка:* вывод **инициирует человек**; автовывода нет; нужна сессия
панели. Через Integration API вывода не существует вовсе.
Proof: `bot/handlers/balance.py`, `bot/automation/panel.py:2370`;
`bot/tests/test_dead_buttons.py` (следит, чтобы `withdraw_balance` не
вернулся).

## «Работа с отзывами»
→ *Оговорка:* бот отзывы **читает и уведомляет о новых**. Отвечать на них он
не умеет. Идёт через панель — в API отзывов нет.
Proof: `bot/handlers/stats.py` (`reviews_menu`), `bot/tasks/manager.py:4203`.

## «Полная аналитика магазина»
→ *Оговорка:* журнал операций читается **через панель**; без живой сессии
остаётся локальная история, и она неполная. Бот об этом говорит.
Proof: `bot/stats_source.py` (`PANEL` / `LOCAL`).

## «Автовозврат зависших заказов»
→ *Оговорка:* по умолчанию **выключен**; в режиме `any` может вернуть деньги
за заказ, выданный вручную; потолок 3 возврата в сутки.
Proof: `bot/storage.py` (`_DEFAULT_SETTINGS["auto_refund"]`),
`bot/tasks/manager.py:2612`.

## «Бот берёт заказы в работу автоматически»
→ *Оговорка:* на этом маркетплейсе действие «в работу» может быть показано
покупателю как «магазин сообщил, что выполнил заказ» — поэтому ручная кнопка
из карточки заказа **убрана намеренно**, а в автопилоте это осознанный выбор
с показом настоящего статуса.
Proof: `bot/keyboards/main.py:order_actions_keyboard` (комментарий прямо об
этом), `bot/tasks/manager.py:2453` (`_maybe_accept_order`).

## «Бот работает без сбоев / 24/7»
→ *Оговорка:* обещание аптайма никто не давал. Что **можно** сказать: бот сам
замечает, когда перестал получать сообщения от Telegram, и говорит об этом
владельцу — с обязательным отбоем, когда приём восстановился.
Proof: `bot/main.py:363` (`_POLLING_GRACE = 90.0`), `:366` (`polling_silent`),
`:410` (`WatchPolling`), `recovered()`.

# UNSAFE CLAIMS

Нельзя писать нигде: ни на сайте, ни в рекламе, ни в переписке, ни как
«скоро», ни как «в разработке».

| Нельзя | Почему |
|---|---|
| **«Управление ценами», «автопереоценка», «демпинг», «подстройка под конкурента»** | бот **не умеет менять цену**. У товара в панели нет поля цены; через API не проверено ни разу. Экран цен — только просмотр. Proof: `bot/handlers/prices.py` (докстринг), `docs/FEATURES.md` |
| **«Автоматический вывод средств», «вывод по расписанию»** | автовывода нет. Ключ `auto_withdraw` — легаси-имя, внутри реквизиты. Proof: `bot/storage.py` (`_DEFAULT_SETTINGS["auto_withdraw"]`) |
| **«Поднятие объявлений через API»** | такого метода в Integration API нет. `bump_ad` удалён, тест следит. Proof: `bot/tests/test_dead_buttons.py` |
| **«Автоответы на отзывы»** | бот отзывы только читает |
| **«Автовыдача Telegram Stars»** | раздел скрыт целиком (`features.STARS_HIDDEN = True`): покупка на Fragment не доведена. Ни кнопки, ни команды у продавца нет |
| **«Копирование товаров», «залив», «массовое создание объявлений»** | закрыто флагом `features.ad_templates_shown` — только администратору. Подписчик этого не видит |
| **«Проверяем вашу оплату автоматически»** | оплата идёт вне бота. Кнопка называется «передал владельцу» |
| **«Автоматика на всех ваших магазинах одновременно»** | циклы работают на активном аккаунте |
| **«Гарантируем первое место / топ выдачи»** | бот управляет платным поднятием, а не алгоритмом маркетплейса |
| **«Автовыдача PUBG»** | плагина нет; `/pubg` так и отвечает |
| **«Мы покупаем коды за вас»** | покупка идёт **ключом и деньгами продавца** |
| **«Пополнение аккаунта Roblox»** | у поставщика Roblox только `voucher` — выдаётся код, активирует покупатель |
| **«Работает с PlayerOK»** | интеграции нет, в коде совпадений нет |
| **«Бесплатно 7 дней»** (как единственная формулировка) | это половина правды: 3 дня без условий + 7 за подписку на канал |
| **«Не требует ваших ключей поставщика»** | требует: ключ AppRoute вводит продавец |
| **«Мгновенно», «в ту же секунду»** — про что угодно | минимальный период опроса — 10 с для чатов и 60 с для заказов |

## Правило на будущее

Новая формулировка допустима, если её можно закончить фразой **«потому что в
коде есть…»** и назвать файл. Если такого файла нет — утверждение идёт в
UNSAFE, а не «на усмотрение копирайтера».
