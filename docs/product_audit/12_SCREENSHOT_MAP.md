# 12. Карта материалов для съёмки

Что нужно снять для сайта и Telegram. Для каждого материала: функция · экран ·
что должно быть видно · **что скрыть** · формат · приоритет.

---

## Правила безопасности съёмки — читать до первого скриншота

**Никогда не попадает в кадр:**

| Что | Почему |
|---|---|
| **Токен Integration API** — полностью или частично | это доступ к магазину |
| **Куки панели** (`stel_*`, сессионные) | доступ к кабинету |
| **Seed-фраза TON** — любой её фрагмент | доступ к кошельку |
| **Ключ поставщика** (AppRoute, ns.gifts) | доступ к деньгам на счёте поставщика |
| **Строка прокси** с логином и паролем | в боте она и так показывается только хостом и портом |
| **Номер карты и реквизиты оплаты** | чужие деньги |
| **Telegram ID продавца, ник и имя покупателя** | персональные данные |
| **Настоящие коды товара** в журнале выдач | это товар, который можно активировать |
| **Номера заказов и чатов** | по ним находится покупатель |
| **Адрес сервера, IP, имена переменных окружения** | инфраструктура |
| **Код сборки (`/version`)** и любые служебные экраны | они скрыты от продавца намеренно |

**Как снимать безопасно:**
1. Лучший вариант — **отдельный демонстрационный магазин** с вымышленными
   названиями товаров и тестовыми заказами.
2. Второй вариант — замазывать **сплошной плашкой**, а не блюром: блюр с
   цифрами местами восстанавливается.
3. Названия товаров, если они настоящие, заменять на нейтральные.
4. Перед публикацией — просмотреть кадр целиком, включая шапку экрана: там
   стоит название магазина.

## Приоритет 🔴 — нужно для запуска сайта и первой волны постов

### S-01. Выдача кода — главный материал
* **Функция:** F1 автовыдача.
* **Экран:** чат заказа на стороне покупателя, где появился код.
* **Видно:** пришёл заказ → через минуту сообщение с кодом.
* **Скрыть:** ник и имя покупателя, номер заказа, сам код (заменить на
  `XXXX-XXXX-XXXX`).
* **Формат:** **GIF или короткое видео** (10–15 с) — это единственный
  материал, где движение важнее статики.
* **Где используется:** Hero сайта, пост F-01.

### S-02. Экран «⚡ Автопилот» целиком
* **Функция:** I1.
* **Видно:** список автоматик по группам, переключатели, пометка у платных,
  предупреждение у включённой-но-молчащей, четыре пресета.
* **Скрыть:** ничего — экран безопасен.
* **Формат:** длинный скриншот (возможно, два кадра со стыком).
* **Где:** блок «Автоматизации», посты F-06, F-07, A-04.

### S-03. Экран «🧩 Плагины» со списком карт
* **Функция:** F1.
* **Видно:** 13 видов, состояние каждого.
* **Скрыть:** ничего.
* **Формат:** скриншот.
* **Где:** блок ключевых возможностей, пост F-02.

### S-04. Отчёт об остатках с двумя числами
* **Функция:** A5.
* **Видно:** строка «отправлено, принял N, в списке пока M» и кнопка
  «🔄 Проверить остаток».
* **Скрыть:** содержимое позиций (это коды), номер товара.
* **Формат:** скриншот.
* **Где:** блок «Честность продукта», посты P-05, E-01.

### S-05. Экран «🔍 Почему молчит»
* **Функция:** C4.
* **Видно:** причина дословно — например, «пауза между ответами — ещё 12 мин».
* **Скрыть:** номер чата и заказа.
* **Формат:** скриншот.
* **Где:** блок «Честность», пост F-10.

### S-06. Экран доступа с двумя пробами
* **Функция:** J4.
* **Видно:** обе кнопки с числом дней на каждой.
* **Скрыть:** ничего.
* **Формат:** скриншот.
* **Где:** Hero-CTA, пост C-01.

### S-07. Статистика с подписью источника
* **Функция:** E1.
* **Видно:** выручка, число заказов и строка о том, откуда взяты цифры.
* **Скрыть:** настоящие суммы (можно снять на демо-магазине), название
  магазина.
* **Формат:** скриншот.
* **Где:** блок ключевых возможностей, пост F-08.

### S-08. Схема «как это работает»
* **Функция:** архитектура.
* **Что показать:** три шага — подключить токен → включить нужное → бот
  работает на сервере.
* **Формат:** **схема, не скриншот.**
* **Где:** блок 6 сайта, пост C-02.

## Приоритет 🟡 — вторая волна

### S-09. Карточка наблюдения за позицией
* **Функция:** G4.
* **Видно:** порог позиции, защита от демпинга, минимальная цена, интервал.
* **Скрыть:** название товара, адрес страницы витрины.
* **Формат:** скриншот.
* **Где:** посты F-04, F-05.

### S-10. Настройки автоответов
* **Функция:** C4.
* **Видно:** пауза 30 мин, потолок 3, тихие часы 22:00–09:00.
* **Скрыть:** тексты правил, если в них есть контакты.
* **Формат:** скриншот.
* **Где:** пост F-09.

### S-11. Экран автовосстановления
* **Функция:** G5.
* **Видно:** «возвращать сразу после продажи» и «не публиковать распроданное».
* **Скрыть:** ничего.
* **Формат:** скриншот.
* **Где:** пост F-03.

### S-12. Экран «👥 Аккаунты»
* **Функция:** J1.
* **Видно:** два-три магазина, отмечен активный.
* **Скрыть:** **настоящие названия магазинов** — заменить вымышленными.
* **Формат:** скриншот.
* **Где:** блок 5 сайта, пост F-12.

### S-13. Дозапрос поля после отказа панели
* **Функция:** A2.
* **Видно:** сообщение вида «панель просит поле „Регион" — пришли значение».
* **Скрыть:** название товара.
* **Формат:** скриншот.
* **Где:** пост F-11.

### S-14. «Вручную против бота» — сравнение
* **Функция:** M-01.
* **Что показать:** семь шагов ручной выдачи против одного «бот сделал».
* **Формат:** **схема или before/after картинка.**
* **Где:** пост M-01.

### S-15. Журнал выдач
* **Функция:** F1.
* **Видно:** список выдач с датами и номиналами.
* **Скрыть:** **коды целиком** (это товар), ники покупателей, номера заказов.
* **Формат:** скриншот.
* **Где:** блок «социальное доказательство» как демонстрация реальной работы.

## Материалы, которые снимать НЕЛЬЗЯ

| Экран | Почему |
|---|---|
| `/version` | служебный, скрыт от продавца намеренно; печатает хранилище и состояние опроса |
| Любой `*_debug` владельца | печатает сырые ответы маркетплейса и панели |
| 👑 Админ-панель | это кабинет владельца, не возможность продукта |
| Экран AutoStars и Fragment | раздел скрыт флагом; снимать значит обещать несуществующее |
| Экраны копии товара и залива | закрыты флагом `ad_templates_shown` |
| Экран ввода токена **с введённым токеном** | доступ к магазину |
| Экран ввода seed-фразы | доступ к кошельку |

## Сводка: что снять в первую съёмочную сессию

Один демонстрационный магазин, один час:

1. S-06 экран доступа с пробами;
2. S-02 автопилот (два кадра);
3. S-03 плагины;
4. S-10 настройки автоответов;
5. S-11 автовосстановление;
6. S-12 аккаунты (с вымышленными названиями);
7. S-07 статистика;
8. S-05 «почему молчит»;
9. S-04 отчёт об остатках;
10. S-01 видео выдачи — **отдельно**, нужен настоящий тестовый заказ.

Схемы S-08 и S-14 рисуются, а не снимаются.
