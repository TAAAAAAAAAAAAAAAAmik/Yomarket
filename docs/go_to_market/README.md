# Система выхода на рынок: Юмаркет Менеджер

Двадцать восемь документов, превращающих продуктовый аудит в систему продаж:
сайт, Telegram, реклама, onboarding, удержание.

**Источник истины — `docs/product_audit/`.** Здесь нет ни одного утверждения о
продукте, которого нет в аудите. Если понадобится новое — оно сначала
проверяется по коду и добавляется в аудит, и только потом сюда.

## Пять правил, нарушение которых ломает систему

1. **Ничего не придумывать.** Каждое обещание проверяется по аудиту. Новое
   утверждение сначала доказывается кодом.
2. **Ограничения называются там же, где возможности** — не мелким шрифтом
   внизу. Продукт продаётся честностью; спрятанная оговорка стоит дороже, чем
   несделанная продажа.
3. **Никакого выдуманного соцдоказательства.** Отзывов у продукта пока нет.
   Один поддельный обесценивает всё остальное.
4. **Никаких цифр, которых нет в аудите.** Ни потерь в рублях, ни процентов
   роста, ни числа пользователей, ни целевых конверсий.
5. **Скрытое флагами — не существует.** Копия товара, залив и Telegram Stars
   не упоминаются нигде, даже как «скоро».

## Что известно и чего нет

**Известно из кода:** весь состав функций, значения по умолчанию, периоды
циклов, лимиты, ограничения площадки и поставщиков, что продукт умеет и чего
не умеет.

**Неизвестно, и это честно отмечено по тексту:**

| Пробел | Где отмечен | Как закрыть |
|---|---|---|
| Соцдоказательство | `24`, `14` В-17 | собрать отзывы с согласия подписчиков |
| Сколько магазинов у среднего продавца | `02`, `27` | опрос в канале |
| Что стало последней каплей перед оплатой | `27` | интервью с первыми клиентами |
| Чего не хватило неоплатившим | `23`, `27` | вопрос в конце пробы |
| Нормы конверсии | `27` | первый месяц даёт базу |

Любой из этих ответов меняет приоритеты. До тех пор система — обоснованная
гипотеза, выведенная из устройства продукта, а не проверенный факт.
