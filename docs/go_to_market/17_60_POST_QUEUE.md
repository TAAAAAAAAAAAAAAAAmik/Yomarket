# 17. Очередь из 60 публикаций

Готовая очередь. Полные тексты не пишутся — это задания на посты.

**Формат записи.** Номер · тип · стадия · тема · функция · pain · hook ·
главная мысль · proof · media · CTA · приоритет.

**Приоритет:** 🔴 обязательный · 🟡 важный · ⚪ по возможности.

**Ритм.** Подряд не идут два поста одного типа, кроме пары «боль → решение»,
где второй обязан выйти в пределах двух дней. На каждый конверсионный —
минимум три неконверсионных (окно в десять публикаций).

**Частота.** Волна 1 — три в неделю. Дальше — две.
