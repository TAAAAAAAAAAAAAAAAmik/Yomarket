# Заготовки сообщений

Готовые формулировки для повторяющихся задач. Скопировать и дополнить, либо
сказать сессии: «возьми `docs/prompts/имя.md`».

Смысл не в экономии печати, а в том, чтобы не забывать **сказать главное**.
Почти каждая долгая яма в этом проекте начиналась с сообщения, где не хватало
одной строчки: какой товар, какой заказ, что показал экран.

| Файл | Когда |
|---|---|
| `новая-сессия.md` | открыли вторую сессию параллельно первой |
| `пункт-чеклиста.md` | проверили пункт вживую, надо отметить |
| `не-работает.md` | что-то не сработало, нужен разбор |
| `перед-деньгами.md` | собираетесь включить платную функцию |
