## Как делить работу

По областям, а не по времени. Две сессии в одном файле — конфликт при каждом
коммите. Естественные границы:

- витрина и позиции: `automation/market.py`, `automation/position.py`,
  `handlers/selenium_settings.py`
- панель и деньги: `automation/panel.py`, `handlers/balance.py`
- чаты и автоответы: `bot/autoreply.py`, `tasks/manager.py`
- звёзды: `automation/fragment.py`, `handlers/plugins.py`

`CHECKLIST.md` и `handlers/start.py` (там `BOT_VERSION`) трогают обе — по ним
`git pull --rebase` обязателен.
