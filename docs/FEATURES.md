# Что умеет Юмаркет Менеджер

Справочник по всем разделам бота: где что лежит, что делает само, а что
надо нажать. Написан по коду, а не по памяти, — если экран здесь описан,
он существует.

Отдельно оговорено то, чего бот **не** умеет: обещание, которого он не
выполнит, дороже отсутствующей строки.

## С чего всё начинается

`/start` показывает один из трёх экранов — какой, зависит от того, что у
тебя уже есть:

| Состояние | Что видно |
|---|---|
| магазин подключён | главное меню |
| доступ открыт, магазина нет | «остался один шаг» + кнопка подключения |
| доступа нет | витрина: что бот умеет, как получить доступ |

**Подключение магазина** — это токен Integration API из панели продавца.
Вставленный в чат, он проверяется сразу: бот здоровается названием твоего
магазина. Отключить — `/logout`.

**Панель продавца** (`⚙️ Настройки → 🌐 Панель продавца`) — вход по email и
одноразовому коду. Она нужна не всему боту, а тому, чего в API нет вовсе:
создание товара, продвижение, отзывы, поднятие. Сессия живёт до выхода;
бот следит за ней сам и говорит, когда она отвалилась.

**Постоянная клавиатура** — «Заказы», «Чаты», «Баланс», «Статистика»,
«Меню» под полем ввода. Показывается один раз; убрать и вернуть —
`/keyboard`.

## Главное меню

Восемь разделов: `🚀 Объявления`, `🛒 Заказы`, `💬 Чаты`, `💰 Баланс`,
`📊 Статистика`, `🧩 Плагины`, `⚡ Автопилот`, `⚙️ Настройки`. Владельцу —
ещё `👑 Админ-панель`.

Названия пунктов меняются в админке: раздел можно переименовать под свой
магазин.

---

## 🚀 Объявления

Список товаров с ценами и статусами, с листанием по страницам (у магазина
на полсотни объявлений одна страница — не «все»).

| Кнопка | Что делает |
|---|---|
| 📦 Товары | список из панели: по категориям или все подряд |
| 💰 Цены | цены всех объявлений одним экраном |
| ➕ Добавить товар | мастер: название, цена, описание, количество, фото, раздел |
| 📦 Паки | группы объявлений, чтобы поднимать их пачкой |
| ⭐ Премиум продвижение | платное поднятие, вручную и по расписанию |
| 🔄 Авто-восстановление | возврат снятых объявлений в продажу |

### Карточка товара

Из списка «📦 Товары» открывается карточка: название, цена, статус, вид
выдачи, остаток. Кнопки — `✏️ Название`, `📦 Остатки`, `🚀 На модерацию`,
`🙈 Скрыть`, `🗑 Удалить`, `⭐ Премиум продвижение`.

**Цену из бота изменить нельзя** — у товара в панели нет такого поля.
Видно её, править — только на сайте.

### Добавить товар

Мастер спрашивает название, цену, описание, количество, фото и раздел
панели.

Обязательные поля раздела панель называет только на последнем шаге — какие
именно, зависит от раздела, и заранее это не узнать. Поэтому мастер читает
отказ, спрашивает недостающее и **досылает товар сам**, а не отправляет
продавца заводить его вручную.

### Остатки

У товара с авто-выдачей остаток — это сами коды или аккаунты. Присылаются
они одним сообщением, по одной позиции в строке: карточка товара →
«📦 Остатки».

**Отправить и доложить об успехе — не одно и то же.** Маркетплейс на
отправку отвечает «принял», а в списке позиции появляются позже. Бот
перечитывает несколько раз и печатает оба числа: сколько отправлено и
сколько уже видно. Кнопка «🔄 Проверить остаток» пересчитывает, ничего не
отправляя, — второй такой же список положил бы те же ключи дважды, и один
код ушёл бы двум покупателям.

### Премиум продвижение

Поднятие объявлений в выдаче — платное, деньгами магазина.

- вручную: выбрать товары и запустить;
- по расписанию: время суток и потолок трат в день;
- каждые N часов;
- **слежение за позицией**: бот смотрит, где товар стоит на витрине, и
  либо предупреждает, либо поднимает сам. Товары добавляются из списка,
  все сразу или по адресу раздела;
- `🧾 Отчёт по тратам` — сколько ушло на поднятия.

### Паки

Группа объявлений с общим именем. Поднять пак — одно нажатие вместо
двадцати.

---

## 🛒 Заказы

Список с листанием, карточка заказа, действия по нему.

- взять в работу, подтвердить, оформить возврат (с отдельным экраном
  подтверждения — кнопки там по одной в строке намеренно, промах пальцем
  возвращает чужие деньги);
- детали заказа: покупатель, товар, сумма, статус, чат;
- уведомление о новом заказе приходит само.

---

## 💬 Чаты

Переписка с покупателями: список чатов, история сообщений, ответ прямо из
бота.

- `✉️ Ответить` — сообщение уходит в чат маркетплейса от имени магазина;
- `📋 Другие чаты вне заказов` — переписка, к которой заказ не привязан;
  `/watch_chat` и `/unwatch_chat` добавляют и убирают такой чат;
- в закрытый заказ маркетплейс писать не даёт — ни боту, ни тебе; бот об
  этом говорит прямо, а не пишет «не дошло, ответь вручную».

**Автоответы** (`⚙️ Настройки → ⚡ Автопилот → Ответы в чате`, тонкая
настройка — `📩 Автоответы`):

- правила «слова покупателя → ответ», срабатывает то, чьё слово длиннее;
- готовые наборы правил, чтобы не писать с нуля;
- запасной ответ, когда ничего не совпало;
- режим «только вне рабочего времени»;
- счётчик срабатываний у каждого правила;
- **если автоответы включены, а правил нет, бот скажет об этом** и отведёт
  туда, где это чинится.

## 🧩 Плагины

### Гифт-карты — 13 видов

Roblox, Apple, PlayStation Store, Xbox, Steam, Amazon, Razer Gold, Airbnb,
Eneba, Twitch, Meta Quest, Battle.net, OZON.ru.

Каждая карта включается отдельно и умеет одно и то же:

| Кнопка | Что делает |
|---|---|
| ▶️ Включить / ⏸ Выключить | автовыдача по заказам этой карты |
| ⚙️ Настройки | регион, слово-опознаватель, автоответ покупателю, заметка, название и описание товара |
| 🚀 Выдать вручную | по номеру заказа |
| 📜 Журнал выдач | что и когда ушло |
| 📦 Наличие и баланс | что есть у поставщика и на какие деньги |
| 🏷 Создать товар | объявление на номинал, который у поставщика **есть** |

Поставщики: **AppRoute** (основной, ключ и прокси задаются в боте) и
**ns.gifts** (для сравнения закупочной цены).

- `/apr_stock <слово>`, `/apr_balance`, `/apr_item`, `/apr_whoami` — каталог,
  баланс, один номинал и адрес, которым тебя видит поставщик (у него белый
  список IP);
- прокси с постоянным адресом задаётся кнопкой и проверяется кнопкой
  «🧪 Годится ли он», а не советом;
- `/ns_stock <слово>`, `/ns_balance` — то же у второго поставщика.

### AutoStars — Telegram Stars

Покупка звёзд на Fragment по заказу покупателя. **Сейчас скрыт**: покупка
доведена не до конца, и показывать то, что может не сработать с твоими
TON, нельзя. Когда откроется — сюда же вернутся `/stars` и диагностика
Fragment.

## ⚡ Автопилот

Один экран, где включается всё, что бот делает сам. Четыре готовых набора:
`✅ Рекомендуемое`, `🚀 Максимум продаж`, `🔔 Только уведомления`,
`🔴 Выключить всё`.

**💬 Общение с покупателем**

| Что | Подробности |
|---|---|
| Отвечать на сообщения | по твоим правилам |
| Ответ на новый заказ | текст задаёшь ты |
| Ответ при возврате | текст задаёшь ты |

**📦 Заказы**

| Что | Подробности |
|---|---|
| Брать заказы в работу | сразу после оплаты |
| Подтверждать заказы | через N часов (по умолчанию 24) |
| Напоминать о зависших | через N часов |

**🛒 Товары**

| Что | Подробности |
|---|---|
| Восстанавливать снятые | раз в N часов |
| Возвращать сразу после продажи | нужно включённое восстановление |
| Премиум по расписанию | время суток, тратит деньги |
| Премиум каждые N часов | тратит деньги |
| Следить за позицией | предупреждать или поднимать |

**🔔 Уведомления**

Новые заказы, сообщения покупателей, жалобы и споры, новые отзывы, баланс
достиг порога, итоги дня в заданный час.

**Экран говорит, когда функция включена, но работать не может** — «нет ни
одного правила», «не задан тариф», «нужно включить восстановление», — и
кнопка ведёт туда, где это чинится.

## Что происходит без тебя

Фоновый цикл работает у всех, у кого подключён магазин.

- **чаты читаются двумя темпами**: «горячие» (покупатель ждёт ответа или
  заказ моложе двух часов) — раз в 10 секунд, все остальные — раз в
  минуту. Темп нащупывается сам: на «сбавьте темп» бот отступает и
  понемногу возвращается;
- новые заказы, сообщения, жалобы, отзывы — уведомления;
- автоответы, авто-принятие, авто-подтверждение, автовозврат;
- автовыдача гифт-карт: покупка у поставщика, ожидание кода, отправка
  покупателю, журнал;
- восстановление снятых объявлений и возврат в продажу после покупки;
- поднятия по расписанию и по интервалу, слежение за позицией;
- итоги дня;
- слежение за сессией панели и за кошельком поставщика.

**«🔍 Почему молчит»** — экран, объясняющий, почему бот не ответил в
конкретном чате: не дошла очередь, правило не совпало, пауза, маркетплейс
не пустит. Причина записывается всегда, а не додумывается потом.

## Доступ и оплата

- **три дня бесплатно** без условий и **семь дней за подписку на канал** —
  берутся по одному разу каждая и **складываются**: вместе десять дней;
- тарифы: 2 недели, 1, 3, 6, 12 месяцев и «Навсегда». Цены задаёт
  владелец;
- покупка идёт в боте: срок → способ оплаты → реквизиты → «✅ Я оплатил».
  Реквизиты копируются нажатием;
- «Я оплатил» — это передача заявки владельцу, а не проверка оплаты: бот
  платёж не видит и врать об этом не станет;
- `/policy` — пользовательское соглашение и политика конфиденциальности,
  `/forget_me` — удаление своих данных. Обе работают и без подписки.

## 👑 Админ-панель

Только для владельца: статистика по всем продавцам, выдача подписки,
чёрный список, тарифы, рассылка, оформление, тексты сообщений, правовые
документы, способы оплаты, переключатель «требовать подписку», управление
админами.

`/log_here <вид>`, набранная в нужной теме форума, привязывает журнал
событий (`users`, `account`, `trial`, `order`, `payment`) к этой теме —
номера бот берёт сам.

## Команды

**В меню у продавца:** `/menu`, `/orders`, `/chats`, `/ads`, `/balance`,
`/stats`, `/prices`, `/keyboard`, `/help`, `/policy`.

**Работают, но в меню их нет:** `/start`, `/proxy`, `/logout`,
`/forget_me`, `/watch_chat`, `/unwatch_chat`, `/pubg`, а также команды
своих поставщиков и своего Fragment: `/apr_login`, `/apr_forget`,
`/apr_stock`, `/apr_balance`, `/apr_item`, `/apr_whoami`, `/apr_debug`,
`/ns_login`, `/ns_forget`, `/ns_stock`, `/ns_balance`.

Остальное — служебное и продавцу не показывается: на такую команду бот
отвечает то же, что на несуществующую.

## Чего бот не умеет

Здесь — то, чего в нём нет, и почему. Это не список планов.

| Чего нет | Почему |
|---|---|
| Изменить цену товара | у товара в панели нет поля цены. Только на сайте |
| Поднять объявление через API | в Integration API этого нет; идёт через панель |
| Вывести средства через API | то же самое |
| Читать отзывы через API | то же самое |
| Опубликовать товар со статусом `unpublish` | маркетплейс запрос принимает, а статус не меняет. Такие публикуются на сайте |
| Придумать остатки для авто-выдачи | остаток такого товара — сами ключи. Их присылает продавец |
| Проверить, что оплата подписки пришла | оплата идёт вне бота, увидеть её он не может |
| Написать в закрытый заказ | маркетплейс не пускает туда никого |
| Автовыдача Telegram Stars | покупка на Fragment не доведена; раздел скрыт целиком |
| Автовыдача PUBG | плагина нет. `/pubg` так и отвечает — выдумывать номиналы за поставщика значит обещать выдачу, которой не будет |
