# Работа с проектом с телефона

Правки в `CLAUDE.md`, `CHECKLIST.md` и заготовки промптов должны попадать
**в репозиторий** — сессия Claude читает его, а не хранилище заметок. Всё
остальное здесь про то, как этого добиться с телефона.

## Способ 1. GitHub в браузере — работает всегда

Ничего не требует: вы уже залогинены, токены не нужны.

1. Открыть файл на github.com в ветке `claude/where-we-left-off-mul8tu`.
2. Карандаш → правка → **Commit changes**.

Неудобно писать длинное, зато не ломается и не требует настройки. Для
отметки в чеклисте или строчки в `CLAUDE.md` — достаточно.

## Способ 2. Obsidian + плагин Git

Приятнее для длинных текстов, но настраивается небыстро.

1. **Сторонние плагины** → выключить ограниченный режим → **Обзор** →
   установить **Git** (автор Vinzent) → включить.
2. Токен доступа: `github.com/settings/personal-access-tokens/new` →
   Repository access: **только Yomarket** → Permissions → **Contents:
   Read and write**. Токен показывается один раз.
3. Палитра команд: Настройки → **Интерфейс** → «Настройка
   инструментария» → добавить «Палитра команд».
4. Палитра → `Git: Clone an existing remote repo` →
   `https://github.com/TAAAAAAAAAAAAAAAAmik/Yomarket.git`, логин GitHub,
   пароль — токен.
5. Палитра → `Git: Switch branch` → **`claude/where-we-left-off-mul8tu`**.
   На `main` работы нет.
6. Настройки плагина: **Pull on startup** включить, **Auto commit-and-sync**
   поставить 0.
7. Настройки → Файлы и ссылки → Исключённые файлы: `bot`, `src`,
   `node_modules` — чтобы код не забивал список заметок.

### Если команды `Git:` не находятся ни в палитре, ни в пикере

Значит плагин не поднялся. Что пробовать по порядку: полный перезапуск
приложения, затем выключить и включить плагин, затем снова перезапуск.
Не помогло — не тратьте на это время, работайте способом 1.

## Чего сюда класть нельзя

Куки Fragment, seed-фразу TON, токены GitHub и API. Хранилище
синхронизируется в тот же репозиторий, то есть ключ уедет туда, куда он
открывает доступ. Телефон теряется чаще ноутбука.

## Что где лежит

| Путь | Кто читает |
|---|---|
| `CLAUDE.md` | сессия Claude — **всегда**, это правила проекта |
| `CHECKLIST.md` | общий журнал приёмки, 27 пунктов |
| `.claude/skills/<имя>/SKILL.md` | сессия Claude, если попросить навык по имени |
| `docs/prompts/*.md` | человек; сессии можно сказать «возьми `docs/prompts/…`» |
